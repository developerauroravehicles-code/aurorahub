# Documents

Bu klasör AuroraHub projesinin tüm dokümantasyon dosyalarını içerir.

## 📚 Dokümantasyon Dosyaları

### 1. KULLANIM_KILAVUZU.md
Kapsamlı kullanım kılavuzu. Sistemin tüm özelliklerini, rolleri, yetkileri ve kullanım senaryolarını detaylı olarak açıklar.

**İçerik:**
- Sistem rolleri ve yetkileri
- Dashboard özellikleri
- Talep (Demand) yönetimi
- Randevu sistemi
- SMS bildirimleri
- Raporlar
- Çalışan yönetimi
- Sistem yönetimi
- Teknik özellikler
- Sık sorulan sorular (FAQ)

### 2. SMS_DOCUMENTATION.md
SMS gönderim sistemi dokümantasyonu. SMS gönderimlerinin ne zaman, hangi şartlarda ve kime gönderildiğini detaylı olarak açıklar.

**İçerik:**
- SMS mesaj tipleri
- SMS gönderim senaryoları
- SMS mesaj formatları
- Teknik detaylar
- Hata yönetimi
- Akış şemaları

### 3. BUG_REPORT.md
Sistemde tespit edilen hataların ve düzeltmelerin kayıt altına alındığı dokümantasyon.

**İçerik:**
- Tespit edilen hatalar
- Hata durumları
- Düzeltme notları
- Test sonuçları

### 4. PERFORMANCE_REPORT.md
Performans testleri ve optimizasyon çalışmalarının dokümantasyonu.

**İçerik:**
- Performans test sonuçları
- Optimizasyon önerileri
- Uygulanan optimizasyonlar
- Bundle size analizi
- Database query optimizasyonları

### 5. performance-reports/
Performans test raporlarının JSON ve Markdown formatlarında saklandığı klasör.

**İçerik:**
- Detaylı performans metrikleri
- Bundle size raporları
- Database query analizleri
- Optimizasyon önerileri

---

## 📖 Kullanım

Her dokümantasyon dosyası bağımsız olarak okunabilir. Yeni özellikler eklendiğinde veya değişiklikler yapıldığında ilgili dokümantasyon dosyaları güncellenir.
